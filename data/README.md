# Data

This directory contains datasets used by MAINTAIN-X.

## Structure

- `raw/` — original downloaded datasets
- `processed/` — cleaned and transformed datasets

Raw and processed datasets are intentionally excluded from Git.

## Initial Dataset

NASA C-MAPSS — Commercial Modular Aero-Propulsion System Simulation.

The dataset is used for predictive maintenance and Remaining Useful Life
(RUL) prediction experiments.
