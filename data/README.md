# Data

This directory holds datasets used by MAINTAIN-X.

## Structure

- `raw/` — original, unmodified datasets (downloaded manually, not committed)
- `processed/` — cleaned and labeled datasets generated by the pipeline (not committed)

## NASA C-MAPSS

C-MAPSS (Commercial Modular Aero-Propulsion System Simulation) is a NASA
simulator of turbofan engine degradation. The public dataset contains run-to-
failure trajectories for engines under multiple operating conditions. It is the
standard benchmark for Remaining Useful Life (RUL) prediction.

Each subset (`FD001`-`FD004`) ships three files:

- `train_<SUBSET>.txt` — full run-to-failure trajectories
- `test_<SUBSET>.txt` — trajectories truncated before failure
- `RUL_<SUBSET>.txt` — the true RUL at the final observed cycle of each test engine

Rows are whitespace-separated with 26 columns: `unit_id`, `cycle`, three
`operational_setting_*` columns and 21 `sensor_*` columns.

## Downloading the dataset

The NASA endpoint is not reliably downloadable from code, so the dataset is
**acquired manually** and the pipeline only **processes it locally**. No network
access is required once the archive is in place.

1. Download the archive from the NASA data repository
   (https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/).
2. Place it in `data/raw/` as `CMAPSSData.zip`.
3. Extract it:

```bash
python -m maintainx.data.download
```

This validates the archive, extracts the text files into `data/raw/CMAPSSData/`
(skipping already-present files) and reports which subsets are complete.

The extraction also accepts archives with different names and nested layouts
(e.g. a wrapper ZIP containing an inner `CMAPSSData.zip`, or a single top-level
`CMAPSSData/` folder).

## Preprocessing

Process a subset into labeled Parquet files:

```bash
python -m maintainx.data.preprocess --dataset FD001
```

This loads the raw text files, generates RUL labels (for training:
`RUL = max_cycle - cycle`; for testing: aligned with `RUL_FD001.txt`), validates
the result and writes:

```text
data/processed/FD001/train.parquet
data/processed/FD001/test.parquet
```

Both files contain the 26 raw columns plus a `rul` column.

## Why raw and processed data are not committed

- The C-MAPSS archive is redistributed under NASA terms and is large.
- `data/processed/` is generated output, reproducible from `data/raw/`.
- Both directories are ignored via `.gitignore` (`data/raw/*`, `data/processed/*`).

Never commit the ZIP, extracted text files, generated Parquet files or model
artifacts to the repository.
