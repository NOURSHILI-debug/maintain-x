# MAINTAIN-X

> An evidence-driven multimodal AI platform for industrial maintenance.

MAINTAIN-X combines predictive maintenance, speech AI, anomaly detection,
retrieval-augmented generation, and agentic workflows to help technicians
diagnose industrial equipment failures.
